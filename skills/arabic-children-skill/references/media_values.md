# الوسيط والصورة والقيم

> مرجع تفصيلي في الكتاب المصور والمسرح والإذاعة والوسيط الرقمي، ثم القيم والحساسية. يُقرأ مع الأبواب ٧–٨ و١٢ من `SKILL.md`.

---

## ١. الكتاب المصور

### ١.١ الصورة لغة

> «الصور الكبيرة فهي لغة الطفل» (شحاته، ص ١٦).

- الصورة تحمل نصف المعنى.
- لا تكرر الصورة ما يقوله النص حرفياً.
- التفاصيل القليلة أفضل.
- الألوان الأساسية للصغار.

### ١.٢ توزيع الصفحة

| القاعدة | التطبيق |
| :--- | :--- |
| مساحة النص | ثلث الصفحة للصغار |
| موضع النص | ثابت |
| الفاصل | لا تكسر الجملة بين صفحتين |
| النهاية | صورة كبيرة للسكوت |

### ١.٣ أنواع الكتب

| النوع | العمر | الوصف |
| :--- | :--- | :--- |
| كتاب مفهوم | ٠–٣ | صورة/كلمة |
| كتاب مصور | ٣–٦ | نص قصير + صورة |
| قصة مبكرة | ٦–٩ | فصول قصيرة |
| رواية صغيرة | ٩–١٢ | فصول |
| رواية يافعين | ١٢+ | نص كامل |
| كتاب معلومات | ٦–١٢ | حقائق + رسوم |
| كتاب نشاط | ٣–٩ | ألعاب |
| ديوان | ٣–١٢ | شعر |

### ١.٤ الغلاف

- صورة واحدة قوية.
- عنوان مقروء من بعيد.
- اسم المؤلف/الرسام.
- ألوان مناسبة للعمر.

## ٢. المسرح

### ٢.١ الخصائص

- المكان محدود.
- الزمن متصل.
- الحوار أثقل.
- التفاعل مباشر.
- الحركة ضرورية.

### ٢.٢ القواعد

- ٣–٥ شخصيات.
- مشهد أو اثنان.
- ١٥–٤٥ دقيقة.
- كل مشهد فيه فعل.
- يمكن مخاطبة الجمهور.
- نهاية واضحة.

**خطأ:** مسرح أطفال كله كلام. الطفل يحتاج حركة وألواناً وأصواتاً.

### ٢.٣ مثال

```text
المكان: حديقة.
الزمن: صباحاً.

سامر: هذه كرتي!
علي: لا، هذه كرتي.
سامر: لكن فيها نجمة.
علي يقلب الكرة.
علي: إذن ليست كرتك.
سامر: أعرف. لكنني أريدها.
علي: لماذا؟
سامر: لأنني لا أريد أن ألعب وحدي.
علي: تعال.
يلعبان.
```

## ٣. الإذاعة

### ٣.١ الخصائص

- الصوت وحده.
- المؤثرات تحل محل الصورة.
- الحوار أوضح.
- الأسماء تُقال.
- لا مشاهد صامتة طويلة.

### ٣.٢ القواعد

- ٥–١٥ دقيقة.
- شخصيات قليلة.
- صوت راوٍ (اختياري).
- مؤثرات مناسبة.
- إيقاع أسرع.

---

## ٤. التلفزيون والفيديو

### ٤.١ الخصائص

- صورة + صوت.
- إيقاع أسرع.
- مشاهد أقصر.
- جذب بصري.

### ٤.٢ القواعد

- ٣–١٠ دقائق.
- مشاهد قصيرة.
- حوار أقل.
- صورة تحمل المعنى.

---

## ٥. الوسيط الرقمي

### ٥.١ الخصائص

- تفاعل.
- نص قصير.
- صوت/حركة.
- خيارات.

### ٥.٢ القواعد

- لا تُغرق الطفل بالخيارات.
- النص قصير.
- التفاعل يخدم الحكاية.
- لا إعلانات مضللة.
- احترم وقت الطفل.

---

## ٦. القيم

### ٦.١ القاعدة

> «الاستهواء هو تقبل آراء الآخرين ممن يُعجب بهم الطفل ويقدّرهم دون نقد» (نجيب، ص ٢٩).

القيمة تصل بالقدوة، لا بالخطبة.

### ٦.٢ جدول

| القيمة | كيف تُرى |
| :--- | :--- |
| الصدق | طفل يكذب ثم يرى الأثر |
| الأمانة | يعيد شيئاً ليس له |
| الشجاعة | يواجه خوفاً صغيراً |
| الصداقة | خلاف ثم صلح |
| الاحترام | جدّ يعلّم حفيده |
| التعاون | عمل جماعي |

### ٦.٣ ما تتجنبه

- الخطبة في النهاية.
- الشخصية التي تتكلم بلسان المربي.
- القيمة قبل أن تُرى.
- المبالغة في الخير.

## ٧. الحساسية

| الموضوع | السؤال | التصرف |
| :--- | :--- | :--- |
| الموت | هل الطفل فقد عزيزاً؟ | عالج بلطف |
| الطلاق | هل الخبر مناسب؟ | ركّز على الأمان |
| الخوف | هل يترك أثراً؟ | اجعل الحل أقوى |
| العنف | هل يخدم الحكاية؟ | احذف ما لا يخدم |
| المرض | هل يحتاج شرحاً؟ | بسّط بلا ترهيب |
| الدين | هل السياق مناسب؟ | احترم بلا تلقين |
| الإعاقة | هل تُقدّم باحترام؟ | شخص لا رمز |
| الفقر | هل يُسخر منه؟ | احترم الكرامة |

**قاعدة:** لا تُخفِ عن الطفل ما يحتاج معرفته، ولا تُقدّم له ما لا يستطيع حمله.
